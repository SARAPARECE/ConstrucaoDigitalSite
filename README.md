# ConstruçãoDigitalSite

Site estático preparado para publicação com GitHub Pages.

## Publicação

O repositório está em:

- https://github.com/SARAPARECE/ConstrucaoDigitalSite

Após ativar GitHub Pages, o site ficará disponível em:

- https://saraparece.github.io/ConstrucaoDigitalSite/

## Ligar domínio OVH (quando tiveres o domínio final)

Na OVH (Zona DNS), configura:

- `A` para domínio raiz (`@`) apontando para:
	- `185.199.108.153`
	- `185.199.109.153`
	- `185.199.110.153`
	- `185.199.111.153`
- `CNAME` para `www` apontando para:
	- `saraparece.github.io`

No GitHub, em **Settings > Pages**, define o domínio customizado e ativa **Enforce HTTPS**.
